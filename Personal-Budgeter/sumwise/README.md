# Sumwise

Personal budget app built with React, JavaScript/JSX, Vite, and Supabase.

## Development

```sh
npm install
npm run dev
```

The app entry point is `src/main.jsx`, and the main React component is `src/App.jsx`.

## Commands

- `npm run dev`: start the development server with hot module replacement.
- `npm run build`: create a production build in `dist`.
- `npm run lint`: check JavaScript and JSX with ESLint.
- `npm run preview`: preview the production build locally.

Vite is configured in `vite.config.js`, and ESLint is configured in `eslint.config.js`.
